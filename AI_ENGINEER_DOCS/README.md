# AI Engineering Archive

Welcome to the AI Engineering Archive. This repository contains essential resources, documentation, and interview preparations for aspiring AI Engineers, particularly geared towards intern candidates.

## Directory Structure

*   `interviews/`: Contains common interview questions, answers, and study materials.
    *   `question-ai-engineer.md`: A curated list of common AI Engineer interview questions.

## Purpose

The main goal of this repository is to serve as a personal knowledge base and study guide for tackling AI engineering challenges and technical interviews.
